## Migration and scope

Version 2 saves retain original v1 guest/account keys; legacy games become Classic.
Unreadable v2 saves never silently fall back. Once an account accepts v2, old v1-only
clients cannot overwrite it (HTTP 426). Preserve v2 saves and use compatible code for
rollback. Guest history is separate; account history remains private with pending
changes preserved. No SQL migration, automatic guest import or rating reset.
