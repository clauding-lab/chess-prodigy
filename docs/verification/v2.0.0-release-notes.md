# Chess Prodigy 2.0.0 — opponent personalities and recorded games

Chess Prodigy 2.0 adds recorded computer games, move replay and rematches, with an
optional Paul Morphy playing style and coaching review that evaluates independently
of the opponent. Classic ratings, accounts, friend matches, stories and offline guest
play remain supported.

## What's new

- **Games and replay:** browse up to 200 completed computer games and replay legal moves
  without changing your current position or rating.
- **Private opponent records:** retained wins, draws and losses by opponent version and
  difficulty, separating assisted and unassisted games. Older unknown assistance is
  labelled; these are not lifetime totals.
- **Rematch:** reuse opponent, difficulty, colour and clock settings, with setup available
  before starting. Each rematch gets a new game ID; Morphy rematches also get a new seed.
- **Paul Morphy beta:** optional attack-and-development preferences at Casual, Club and
  Strong difficulty. No account is required. Selection is off by default and every
  Morphy game is unrated.
- **Independent review:** neutral hints and move annotations reject opponent-derived,
  stale or incompatible evaluation data, including restored legacy caches.
- **Clearer Practice Rating:** the same existing calculation, described as an in-app
  measure rather than an official FIDE rating.
- **Timeout correction:** a flagged game is drawn when the opponent has only a king.
- Includes the post-1.2 H2H tab, temporary chat, unread indicator, touch-audio retry and
  abandonment-rating preview described in the changelog.

## Try the optional beta

Use Node 22.19+ and install the locked dependencies with `npm ci`, then:

```sh
VITE_PERSONALITY_BETA=true npm run dev -- --port 5173
```

Open `http://127.0.0.1:5173`, select **New game**, then **Paul Morphy**. For a built
application, set `VITE_PERSONALITY_BETA=true` on `npm run build`; changing only the
server's startup environment cannot change an existing frontend build.

## Save compatibility

Version 2 saves retain original v1 guest/account keys for recovery. Legacy games become
Classic; unreadable v2 saves never silently fall back. Once an account accepts v2,
v1-only clients cannot overwrite it. Keep v2 data and restore compatible code if rolling
back. There is no database schema migration, automatic guest-history import or rating
reset. Unknown opponents remain read-only; damaged history is preserved for download.
Recovery downloads do not currently have an in-app import screen.

## Release scope

This is a source release; publishing it does not deploy the hosted application.
Morphy remains a default-off, unrated beta. Playing-strength calibration, historical
fidelity and commercial naming clearance are not established. Physical iPhone
installation, audio and lifecycle checks remain outstanding; browser emulation does not
prove those results. No Stockfish, paid services or external analytics were added.
